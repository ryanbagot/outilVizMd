# Accessibilité et prise en main — état des preuves

Les parcours XCUITest exécutent l’ouverture, l’annulation, la navigation, la fermeture, Cmd+F, Échap, les flèches de résultats, Cmd+, les réglages et les messages de suivi externe dans la vraie interface macOS. Les actions disposent de noms et d’identifiants accessibles ; les états sont en français. Les deux apparences et le contraste ont des contrats de présentation.

Ce contrôle automatisé ne remplace pas un audit VoiceOver complet. Le parcours humain SC-007 n’a pas été réalisé : aucun groupe de cinq débutants n’était disponible pendant l’exécution. Il faut mesurer avec l’aide locale seule le nombre de réussites sous cinq minutes et relever les obstacles. Aucun résultat humain ni durée n’est déduit des tests UI.

T082 reste non validée avant ces essais. Utiliser l’aide accessible par Aide → Aide outilVizMd ; ne donner aucune instruction supplémentaire aux participants pendant le parcours mesuré.
